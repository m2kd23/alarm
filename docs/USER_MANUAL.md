# 사용자 설명서

## 실행과 종료

`InternalAlarmApp.exe`를 실행하면 알림 목록이 열리고 작업 표시줄 알림 영역(시스템 트레이)에 아이콘이 생깁니다. 목록 창의 X를 눌러도 프로그램은 종료되지 않습니다. 완전히 종료하려면 트레이 아이콘을 오른쪽 클릭하고 **종료**를 선택합니다.

## 문장을 선택해 빠르게 등록하기

1. 한글, Word, Excel, Outlook, 메모장, Edge, Chrome, PDF 뷰어 등에서 일정이 들어 있는 문장을 선택합니다.
2. `Ctrl + Caps Lock`을 한 번 누릅니다. Ctrl을 누른 상태에서 Caps Lock을 누르면 됩니다. 앱이 Caps Lock 입력을 가로채므로 영문 대문자 입력 상태는 바뀌지 않습니다.
3. 등록 창에서 추출된 제목·날짜·시간을 확인하고 필요한 부분을 고칩니다.
4. **저장**을 누릅니다.

선택 영역을 직접 읽을 수 없는 프로그램에서는 잠시 복사 동작을 사용한 후 기존 Clipboard 내용을 복원합니다. 한글처럼 복사가 늦게 완료되는 프로그램은 자동으로 한 번 더 시도합니다. 아무 문장도 선택하지 않았다면 빈 등록 창에서 직접 입력할 수 있습니다.

현재 열려 있는 HWP/HWPX·Word·Excel·PowerPoint 문서의 전체 경로나 Edge·Chrome·Firefox의 웹 주소를 확실하게 확인할 수 있으면 **파일 / 폴더 / 웹** 칸에 자동 입력합니다. 프로그램 버전이나 보안 설정 때문에 경로를 확인할 수 없는 경우에는 빈칸으로 두며 사용자가 직접 선택할 수 있습니다. 로컬 HTML 주소(`file:///...`)는 Windows 파일 경로로 변환됩니다.

## 날짜와 시간 표현

`2026년 8월 20일`, `8월 20일`, `8/20`, `8.20`, `오늘`, `내일`, `모레`, `금요일`, `이번주 금요일`, `다음주 화요일`을 인식합니다. 시간은 `오후 3시`, `오전 10시`, `15시`, `15:30`, `오후 3시 30분` 형식을 인식합니다. 인식되지 않은 값은 사용자가 직접 입력합니다.

## 사전·반복 알림

등록 창에서 5분, 10분, 30분, 1시간, 1일 전을 여러 개 선택할 수 있습니다. 직접 지정 값은 분·시간·일 단위를 지원합니다. 반복 알림은 5/10/30분 간격과 횟수(1/2/3/5회 또는 확인할 때까지)를 선택합니다.

## 알림 확인과 다시 알림

알림 시간이 되면 `[내 업무 알림]` 자체 팝업 하나만 표시됩니다. 시스템 트레이 아이콘은 목록·설정·종료 메뉴를 위해 계속 유지됩니다.

- **확인**: 일정을 완료하고 남은 반복 알림을 중지합니다.
- **다시 알림**: 선택한 5/10/30/60분 뒤에 다시 알립니다.
- **파일/폴더/웹 열기**: 등록된 경로 또는 http/https 주소를 Windows 기본 프로그램·탐색기·브라우저로 엽니다.

## 목록 관리

상단에서 전체, 오늘, 이번 주, 예정, 완료 일정을 필터링할 수 있습니다. 검색란에는 제목 또는 설명 일부를 입력합니다. 열 머리글을 누르면 정렬됩니다. 일정을 선택한 뒤 수정, 완료, 삭제, 파일 열기를 사용할 수 있으며 행을 두 번 누르면 수정 창이 열립니다.

## 설정

기본 단축키는 한글·Word·Excel·Windows 기본 기능과의 충돌 가능성이 낮은 `Ctrl + Caps Lock` 한 번입니다. 설정에서 `Ctrl + Alt + F12` 한 번 또는 Scroll Lock, Pause/Break, F8, F9 두 번 방식도 선택할 수 있고 두 번 입력 인정 시간을 200~2000ms로 조정할 수 있습니다. **Windows 로그인 시 자동 실행**은 현재 사용자에게만 적용되어 관리자 권한이 필요 없습니다.

## 모닝 브리핑과 데일리 랩업

설정에서 모닝 브리핑을 **프로그램 시작 시** 또는 **매일 지정 시각** 중 하나로 선택할 수 있습니다. 모닝 브리핑은 오늘 일정 전체를 시간순 카드로 보여줍니다. 지정 시각을 지나 프로그램을 시작하거나 PC가 절전 상태였다면 자동으로 늦게 표시하지 않으며, 시스템 트레이의 **모닝 브리핑** 메뉴에서 직접 열 수 있습니다.

데일리 랩업은 설정한 시각에 오늘 완료 처리한 건수, 오늘 일정 완료율, 미완료 목록을 표시합니다. 미완료 업무는 카드별 **내일로 연기**로 옮기거나, 날짜 선택기에서 원하는 미래 날짜를 고른 후 한 번에 연기할 수 있습니다. 연기하면 원래 시각을 유지하고 남은 사전·반복 알림을 새 일정 기준으로 다시 만듭니다. 이미 지난 사전 알림은 다시 울리지 않습니다.

## 여러 연결 대상 등록

하나의 업무에는 파일, 폴더, 웹 주소를 최대 20개까지 연결할 수 있습니다. 등록 창에서 유형을 선택해 대상과 표시 이름을 추가합니다. 사내 공유 폴더는 `\\서버\공유` 형식으로 등록할 수 있으며, 저장할 때는 경로 형식만 확인하고 실제 접근 가능 여부는 열 때 확인합니다. 알림·브리핑·랩업·목록의 **연결 대상 열기** 버튼은 등록한 대상을 순서대로 엽니다.

## CSV 가져오기와 내보내기

목록 상단의 **CSV 가져오기**는 UTF-8 형식의 CSV만 받습니다. Excel에서는 파일을 **CSV UTF-8(쉼표로 분리)(*.csv)** 형식으로 저장해 주세요. 가져오기 전 정상·중복·오류 행을 미리 보여 주며, 동일 제목과 일시가 있으면 기본적으로 건너뜁니다. 미완료 과거 일정은 가져오지 않습니다.

**CSV 내보내기**에서 시작·종료 날짜를 선택하면 제목, 일시, 상태, 설명, 사전·반복 알림, 연결 대상(최대 10개)을 포함한 주간 업무 파일을 만듭니다. CSV에는 업무 정보가 들어 있으므로 승인된 저장 위치와 공유 권한을 확인하세요.
