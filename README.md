# Alarm — 기억해야 할 일을 놓치지 않도록

**업무 중 발견한 '기억해야 할 일'을 바로 등록하고, 때가 되면 알려주며, 클릭 한 번으로 관련 문서나 웹페이지까지 다시 열어주는 Windows 업무 알림 도구입니다.**

---

## 왜 만들었나요?

업무를 하다 보면 문서, 그룹웨어, 웹페이지, 메일 등을 보다가 **기한을 지켜 처리해야 할 일**, **회의**, **보고**, **확인해야 할 사항**을 발견하게 됩니다.

메모장이나 수첩에 적어 두더라도 시간이 지나면 잊기 쉽고, 일정이 다가왔을 때는 **관련 문서나 웹페이지를 다시 찾아야 하는 번거로움**도 생깁니다.

**Alarm**은 이 두 가지 불편을 한 번에 줄이는 것을 목표로 합니다.

### 기존 방식과의 개선 사항

| 기존 방식의 불편 | Alarm으로 해결 |
|---|---|
| 기억해야 할 내용을 따로 메모해야 함 | 필요한 **텍스트를 선택**해 바로 등록 |
| 메모해도 시간이 되면 잊을 수 있음 | 지정한 일시에 **Windows 알림** |
| 관련 문서나 웹페이지를 다시 찾아야 함 | 알림에서 클릭하면 **관련 문서·웹페이지 바로 열기** |
| 일정과 자료가 서로 떨어져 있음 | **해야 할 일 + 일시 + 관련 자료**를 함께 저장 |

---

## 사용 방법 — 4단계

### 1단계. 기억해야 할 내용 발견
문서, 웹페이지, 그룹웨어에서 처리해야 할 일을 찾습니다.

### 2단계. 필요한 텍스트 선택
예: "8/21 오후 3시 보고"

### 3단계. 일시와 관련 자료 등록
- 날짜 · 시간
- 관련 문서 · URL 저장

### 4단계. 때가 되면 알림
클릭 → 문서/웹페이지 자동 열기

---

## 실제 사용 예시

### 예시 1. 보고 기한을 발견했을 때

**업무 문서에서 발견:**
```
8월 21일 오후 3시까지 AI 교육계획 보고
```

**Alarm에 등록:**
| 항목 | 내용 |
|---|---|
| 제목 | AI 교육계획 보고 |
| 일시 | 2026-08-21 15:00 |
| 사전 알림 | 1일 전 / 1시간 전 / 10분 전 |
| 관련 문서 | C:\업무\AI교육\교육계획.docx |

**알림 표시:**
```
기억해야 할 일

AI 교육계획 보고
오늘 15:00

10분 남았습니다.

[관련 문서 열기]   [다시 알림]   [완료]
```

[관련 문서 열기]를 클릭하면 등록해 둔 문서를 바로 확인할 수 있습니다.

---

### 예시 2. 웹페이지에서 회의 일정을 발견했을 때

**웹페이지 또는 그룹웨어에서 확인:**
```
8월 25일 오전 10시 AI 추진과제 점검회의
```

**Alarm에 등록:**
| 항목 | 내용 |
|---|---|
| 제목 | AI 추진과제 점검회의 |
| 일시 | 2026-08-25 10:00 |
| 관련 URL | https://example.go.kr/meeting/1234 |

회의 시간이 가까워지면 알림을 받고, 알림의 링크를 클릭해 **관련 웹페이지로 바로 이동**할 수 있습니다.

## 핵심 기능

| 기능 | 설명 |
|---|---|
| **텍스트 기반 등록** | 문서·웹페이지·그룹웨어 등에서 필요한 내용을 선택하여 기억할 일로 등록 |
| **날짜·시간 등록** | 선택한 내용의 일정 확인 또는 사용자가 직접 날짜·시간 입력 |
| **사전 알림** | 정시, 5분 전, 10분 전, 30분 전, 1시간 전, 1일 전 등 설정 |
| **관련 문서 연결** | 업무와 관련된 파일 또는 폴더 경로를 함께 저장 |
| **관련 웹페이지 연결** | 업무와 관련된 URL을 일정과 함께 저장 |
| **알림에서 바로 열기** | 알림을 클릭해 등록한 문서·폴더·웹페이지를 바로 실행 |
| **완료 관리** | 처리한 업무는 완료 상태로 변경 |
| **수정·삭제** | 등록된 기억할 일의 일정·내용·링크 수정 및 삭제 |
| **로컬 저장** | 업무 데이터는 사용자 PC 내부에 저장하는 것을 기본 원칙으로 함 |
| **모닝 브리핑 · 퇴근 브리핑** | 오늘 일정 카드와 완료 현황·미완료 일정 연기를 제공 |
| **여러 관련 자료** | 업무별 파일·공유 폴더·내부 URL을 최대 20개까지 연결하고 일괄 열기 |
| **CSV 교환** | UTF-8 CSV로 주간 업무 목록을 미리보기 후 가져오거나 내보내기 |

## 어떤 상황에서 사용하나요?

Alarm은 단순한 시계 알람이 아니라 **업무 중 나중에 다시 기억해야 하는 일을 놓치지 않기 위한 도구**입니다.

### 활용 사례

**문서를 읽다가**
- "금요일까지 회신" 발견 → Alarm 등록

**웹페이지를 보다가**
- "8월 25일 신청 마감" 발견 → Alarm 등록

**회의자료를 보다가**
- "다음 주 화요일 10시 회의" 발견 → Alarm 등록

**보고서를 작성하다가**
- "기관장 보고 전 자료 확인" 필요 → Alarm 등록

**결과**: 필요한 시점에 알림 → 클릭 → 관련 자료 바로 확인

## 등록하는 정보

하나의 '기억해야 할 일'에는 필요한 정보만 간단히 저장합니다.

| 항목 | 예시 | 설명 |
|---|---|---|
| **제목** | AI 교육계획 보고 | 기억해야 할 일 |
| **날짜** | 2026-08-21 | 처리·회의·기한 날짜 |
| **시간** | 15:00 | 알림 기준 시간 |
| **사전 알림** | 1일 전, 1시간 전 | 미리 알려줄 시점 |
| **설명** | 기관장 보고 전 최종 검토 | 추가 메모 |
| **파일** | C:\업무\AI교육\교육계획.docx | 관련 문서 |
| **폴더** | D:\2026\AI교육 | 관련 업무 폴더 |
| **URL** | https://... | 관련 웹페이지 |
| **상태** | 예정 / 완료 | 업무 처리 여부 |

## 사용 흐름

```
1. 문서·웹페이지에서 기억할 일 발견
           ↓
2. 텍스트 선택 → Alarm 등록창
           ↓
3. 날짜·시간 설정 → 문서·URL 함께 저장
           ↓
4. 지정 시간에 알림 표시
           ↓
5. 알림 클릭
           ↓
6. 관련 문서·웹페이지 자동 열기
```

---

## 알림 형태

```
┌─────────────────────────────────┐
│ 기억해야 할 일이 있습니다        │
│                                 │
│ AI 리터러시 교육계획 보고        │
│ 오늘 15:00                      │
│ 10분 남았습니다.                │
│                                 │
│ [관련 문서 열기] [다시 알림]     │
│              [완료]             │
└─────────────────────────────────┘
```

**알림의 핵심**

Alarm은 단순히 "시간이 되었습니다"라고 알려주는 것이 아닙니다.

→ **무엇을 해야 하는지 알려주고, 그 일을 하기 위해 필요한 자료까지 바로 연결하는 것**이 Alarm의 핵심입니다.

## 시스템 구성

별도의 웹서버나 데이터베이스 서버 없이 사용자 PC에서 독립적으로 실행하는 **Standalone 방식**을 기본으로 합니다.

```
사용자 Windows PC
│
├─ Alarm.exe (프로그램)
│
├─ 기억할 일 데이터
│   ├─ 제목
│   ├─ 날짜 / 시간
│   ├─ 사전 알림
│   ├─ 설명
│   └─ 완료 여부
│
├─ 관련 자료 연결
│   ├─ 파일 경로
│   ├─ 폴더 경로
│   └─ 웹페이지 URL
│
└─ 로컬 저장소
```

## 보안 원칙

공공기관 내부망 업무환경에서 사용할 수 있도록 다음 원칙을 준수합니다.

- 업무정보는 **사용자 PC 내부 저장**을 기본으로 합니다
- 외부 인터넷이나 외부 API에 업무내용을 전송하지 않습니다
- 그룹웨어 ID/PW 등 인증정보를 별도로 수집하지 않습니다
- 불필요한 개인정보를 수집하지 않습니다
- 관리자 권한 없이 실행할 수 있도록 구성합니다
- 로그에 비밀번호·개인정보 등 민감정보를 기록하지 않습니다
- 사용한 외부 라이브러리의 라이선스 및 고지 의무를 사전에 확인합니다
- 웹페이지 연결 기능은 사용자가 접근 가능한 내부망·외부망 주소 범위에서 동작합니다

## 개발 목표

### 핵심 목표
> 기억해야 할 일을 발견한 순간에 등록하고,
> 필요한 순간에 알려주며,
> 그 일을 처리할 자료까지 바로 연결한다.

Alarm은 복잡한 일정관리 시스템을 만드는 것이 목적이 아닙니다.

**업무를 하던 흐름을 끊지 않고 '나중에 해야 하는 일'을 가장 간단하게 기억시켜 주는 것**이 목적입니다.

### 사용 흐름
```
기억해야 할 일 발견
      ↓
바로 등록
      ↓
잊고 업무 계속
      ↓
필요한 순간 Alarm이 알려줌
      ↓
클릭해서 자료 열고 바로 처리
```

## 개발 환경

| 항목 | 내용 |
|---|---|
| 운영체제 | Windows 10/11 x64 |
| 프레임워크 | .NET 8 (`net8.0-windows`) |
| UI | WPF + Windows Forms 시스템 트레이 |
| 언어 | C# (Nullable 사용) |
| 로컬 저장소 | Windows 기본 `winsqlite3.dll` (SQLite) |
| 개발 도구 | .NET 8 SDK, Visual Studio 2022 또는 VS Code |

### 개발 빌드 명령

```powershell
dotnet restore .\InternalAlarmApp.sln --ignore-failed-sources
dotnet build .\InternalAlarmApp.sln -c Release --no-restore
```

단일 실행 파일과 배포 ZIP은 저장소 루트에서 다음 명령으로 생성합니다.

```powershell
.\build_portable.ps1
```

자세한 배포 절차는 [배포 가이드](docs/DEPLOYMENT.md)를 참고하세요.
