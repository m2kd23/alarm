# 보안 설계

- 네트워크: 애플리케이션 코드에는 HTTP, 소켓, 클라우드, 외부 API 호출이 없습니다. 오프라인 및 방화벽 차단 상태에서 동작합니다.
- 포트: 수신·송신 포트를 열지 않으며 서버 프로세스를 실행하지 않습니다.
- 저장 데이터: 일정 제목, 원문, 시각, 설명, 연결 경로를 `%LOCALAPPDATA%\InternalAlarmApp\data\alarm.db`에 평문으로 저장합니다. Windows 사용자 프로필 접근 통제가 보호 경계입니다.
- 개인정보: 계정, 광고, 분석, 원격 로깅, 화면 캡처 기능이 없습니다. 민감정보가 포함된 문장은 등록하지 않는 것을 권장합니다.
- 권한: `asInvoker`로 실행하며 관리자 권한을 요구하지 않습니다. 자동 시작은 현재 사용자의 HKCU Run 항목만 사용합니다.
- Clipboard: UI Automation으로 현재 선택 영역을 우선 읽습니다. 불가능할 때만 Ctrl+C를 전송하며 기존 Clipboard 형식을 메모리에 임시 복사하고 즉시 복원합니다. Clipboard 내용은 로그에 남기지 않습니다.
- 단축키: 저수준 키보드 훅은 설정된 `Ctrl+Caps Lock` 조합 또는 사용자가 선택한 키의 key-down/key-up 상태만 비교합니다. 문자 입력과 입력 내용은 저장하거나 로그로 기록하지 않습니다. 전용 조합의 Caps Lock 이벤트는 활성 업무 프로그램에 전달하지 않으므로 대문자 입력 상태가 바뀌지 않습니다.
- 로그: 시작·종료 및 DB/알림/파일 접근 오류의 종류와 메시지만 날짜별 파일에 기록합니다. 선택 문장이나 Clipboard 전체 내용은 기록하지 않습니다.
- 연결 대상: 활성 프로그램에서 문서 경로나 브라우저 주소 표시줄의 값만 읽고 전체 문서·화면은 수집하지 않습니다. 감지한 경로는 사용자가 저장 전에 확인할 수 있습니다.
- 파일 열기: 허용된 문서·이미지·HTML 파일, 폴더, `http/https` 주소만 Windows Shell 기본 동작으로 엽니다. 실행 파일, 명령 스크립트, `javascript:` 등의 위험한 형식은 차단합니다. 웹 주소는 앱이 직접 내려받지 않고 사용자가 열기 버튼을 누를 때 기본 브라우저로 전달합니다.
