# 사용자 설명서

## 실행과 종료

`InternalAlarmApp.exe`를 실행하면 알림 목록이 열리고 작업 표시줄 알림 영역(시스템 트레이)에 아이콘이 생깁니다. 목록 창의 X를 눌러도 프로그램은 종료되지 않습니다. 완전히 종료하려면 트레이 아이콘을 오른쪽 클릭하고 **종료**를 선택합니다.

## 문장을 선택해 빠르게 등록하기

1. 한글, Word, Excel, Outlook, 메모장, Edge, Chrome, PDF 뷰어 등에서 일정이 들어 있는 문장을 선택합니다.
2. `Scroll Lock` 키를 500ms 안에 두 번 누릅니다.
3. 등록 창에서 추출된 제목·날짜·시간을 확인하고 필요한 부분을 고칩니다.
4. **저장**을 누릅니다.

선택 영역을 직접 읽을 수 없는 프로그램에서는 잠시 복사 동작을 사용한 후 기존 Clipboard 내용을 복원합니다. 아무 문장도 선택하지 않았다면 빈 등록 창에서 직접 입력할 수 있습니다.

## 날짜와 시간 표현

`2026년 8월 20일`, `8월 20일`, `8/20`, `8.20`, `오늘`, `내일`, `모레`, `금요일`, `이번주 금요일`, `다음주 화요일`을 인식합니다. 시간은 `오후 3시`, `오전 10시`, `15시`, `15:30`, `오후 3시 30분` 형식을 인식합니다. 인식되지 않은 값은 사용자가 직접 입력합니다.

## 사전·반복 알림

등록 창에서 5분, 10분, 30분, 1시간, 1일 전을 여러 개 선택할 수 있습니다. 직접 지정 값은 분·시간·일 단위를 지원합니다. 반복 알림은 5/10/30분 간격과 횟수(1/2/3/5회 또는 확인할 때까지)를 선택합니다.

## 알림 확인과 다시 알림

알림 시간이 되면 Windows 알림과 자체 팝업이 함께 표시됩니다.

- **확인**: 일정을 완료하고 남은 반복 알림을 중지합니다.
- **다시 알림**: 선택한 5/10/30/60분 뒤에 다시 알립니다.
- **파일/폴더 열기**: 등록된 경로를 Windows 기본 프로그램 또는 탐색기로 엽니다.

## 목록 관리

상단에서 전체, 오늘, 이번 주, 예정, 완료 일정을 필터링할 수 있습니다. 검색란에는 제목 또는 설명 일부를 입력합니다. 열 머리글을 누르면 정렬됩니다. 일정을 선택한 뒤 수정, 완료, 삭제, 파일 열기를 사용할 수 있으며 행을 두 번 누르면 수정 창이 열립니다.

## 설정

단축키를 Scroll Lock, Pause/Break, F8, F9 중에서 선택하고 두 번 입력 인정 시간을 200~2000ms로 조정할 수 있습니다. **Windows 로그인 시 자동 실행**은 현재 사용자에게만 적용되어 관리자 권한이 필요 없습니다.
