업무비서 (InternalAlarmApp)

1 프로그램 개요 및 주요 가치

구분 상세 내용
프로그램명 업무비서 (InternalAlarmApp)
실행 환경 공공기관 및 기업 폐쇄망 / 내부망 Windows 10·11 x64
주요 용도 문서(한글 HWP/HWPX, MS Office, PDF), 웹 브라우저, 사내 메신저 등에서 일정 문장을 마우스로 선택 후 [Ctrl + Caps Lock]을 누르면, 날짜/시간 및 출처 문서 경로·URL을 자동 추출하여 원하는 시간에 정확히 알림을 제공하는 로컬 상주 도구
4대 핵심 가치 1. 완전 무통신(Air-Gapped): 인터넷/클라우드 연결 없는 오프라인 전용으로 정보 유출 원천 차단
2. 무손실 클립보드 보호: UI Automation 우선 읽기 및 기존 클립보드 원본 즉시 백업/복원
3. 초경량 내장 DB: Windows OS 기본 winsqlite3.dll P/Invoke로 별도 설치 불필요
4. 심층 바로가기(Deep Link): 알림 도래 시 원클릭으로 출처 문서/웹페이지 즉시 열기

구분 기술 / 컴포넌트 버전 / 사양 상세 역할 및 선정 사유

UI 계층 WPF PresentationFramework XAML 기반 직관적 UI, 다크/라이트 테마 및 Per-Monitor DPI 스케일링

로컬 데이터베이스 SQLite (C Native) winsqlite3.dll Windows 내장 C 라이브러리 직접 바인딩으로 외부 패키지 의존성 제로화

4 상세 기능 명세서 (Functional Specification)

기능 ID 대분류 기능명 상세 동작 및 구현 명세
F-01 단축키 전역 단축키 감지 Ctrl + Caps Lock 키 조합을 저수준 키보드 훅으로 감지하여 즉시 팝업 호출. 활성 프로그램의 CapsLock 대소문자 토글 방지
F-02 텍스트 캡처 무손실 텍스트 추출 1차: UI Automation으로 선택 텍스트 획득
2차: 실패 시 클립보드 기존 데이터를 메모리에 백업 후 복사 및 즉시 원본 복원
F-03 문맥 연동 활성 문서 경로 감지 한글(HWP, HWPX), MS Office(Word, Excel, PPT), PDF 등 활성 창의 파일 절대 경로 자동 추출
F-04 문맥 연동 웹 브라우저 URL 감지 Chrome, Edge, Whale 등 주요 브라우저의 활성 탭 주소창 URL 자동 획득 및 알림에 바인딩
F-05 자연어 파싱 한국어 날짜 분석 오늘, 내일, 모레, 이번 주/다음 주 요일, 3월 5일, 2026-08-20 등 상대/절대 날짜 표현 자동 인식
F-06 자연어 파싱 한국어 시간 분석 오전/오후, 24시간제(15:30), 3시 반, 정오, 자정, 1시간 뒤 등 시간 표현 자동 파싱
F-07 알림 등록 빠른 등록 팝업 선택 문장은 제목/설명란에, 파싱된 일시는 날짜/시간 피커에, 파일/URL은 하단 링크란에 자동 매핑
F-08 알림 등록 사전 알림 및 반복 5분/10분/15분/1시간/1일 전 복수 사전 알림 및 매일/매주/매월 반복 옵션 지원
F-09 스케줄러 정밀 타이머 및 복구 초 단위 윈도우 스케줄러로 정밀 알림 트리거 및 PC 재시작 후 누락된 알림 자동 점검
F-10 알림 표출 자체 알림 팝업 창 화면 우측 하단 팝업 표시 (사운드 알림, 확인 완료, 연결 경로 원클릭 열기 지원)
F-11 알림 액션 다시 알림 (Snooze) 5분 / 10분 / 30분 / 60분 / 내일 다시 알림 기능 제공
F-12 안전 실행 출처 파일/URL 열기 연결된 문서나 웹 주소를 Windows 기본 프로그램(한글, 오피스, 브라우저)으로 안전하게 열기
F-13 목록 관리 알림 관리 메인 UI 전체/오늘/이번 주 필터링, 검색, 정렬, 수정, 완료 처리, 일괄 삭제 지원
F-14 환경 설정 트레이 및 자동 실행 시스템 트레이 백그라운드 상주, Windows 시작 시 자동 실행(HKCU Run) 설정

5 보안 점검 결과 및 보안 대책 (Security Assessment)

공공기관 및 기업 보안 규정 준수 확인: 본 프로그램은 인터넷 통신 기능이 전혀 없으며, 관리자 권한을 요구하지 않고 사용자 프로필 격리 영역에만 데이터를 저장하므로 사내 보안 정책에 100% 부합합니다.
점검 분야 보안 점검 항목 점검 결과 적용된 보안 대책 및 구현 세부사항
네트워크 보안 외부 통신 및 정보 유출 적합 (양호) • 소켓, HTTP/HTTPS, WebClient, 외부 API 일체 미사용
• 완전 오프라인(Air-Gapped) 및 방화벽 차단 환경에서 100% 동작
네트워크 보안 포트 개방 및 서버 리스너 적합 (양호) • 인바운드/아웃바운드 포트를 열지 않으며 데몬 서버 프로세스 미실행
단축키 보안 키로거(Keylogger) 오인 방지 적합 (양호) • 설정된 단축키 조합(Ctrl + Caps Lock)만 매칭 검사

클립보드 보호 작업 데이터 클립보드 오염 방지 적합 (양호) • UI Automation 우선 읽기 적용
• 대체 복사 시 기존의 모든 클립보드 데이터를 메모리에 백업 후 텍스트 추출 즉시 원본 복원
권한 관리 최소 권한 원칙 (Least Privilege) 적합 (양호) • 관리자 권한(UAC) 미요구 (asInvoker 실행)
• 레지스트리는 현재 사용자 영역(HKCU)에만 한정 기록

개인정보 보호 로그 내 민감정보 노출 방지 적합 (양호) • 오류 및 구동 상태만 로깅하며 사용자가 선택한 본문 문장 및 클립보드 원문은 로그 파일에 절대 기록하지 않음
악성코드 차단 위험 파일 실행 방지 (Safe Open) 적합 (양호) • 화이트리스트 기반 안전 열기 적용
• 실행 파일(.exe, .bat, .cmd, .ps1, .vbs 등) 및 javascript: 링크 강제 차단

6 종합 결론 및 기대 효과

  • 업무 연속성 극대화: 드래그 후 Ctrl + Caps Lock 1회 클릭만으로 날짜, 시간, 출처 문서 경로가 자동 완성되어 일정 등록에 소요되는 시간 90% 이상 단축.
  • 컨텍스트 스위칭 비용 최소화: 알림 팝업에서 [바로가기 열기]를 누르면 관련 한글 문서나 사내 웹페이지가 즉시 열려 신속한 업무 처리 가능.
  • 공공/기업 폐쇄망 최적화: 무통신, Windows 내장 라이브러리 사용, 무손실 클립보드 복원, 실행 파일 차단 등 강력한 보안 설계로 사내 규정 100% 준수.
