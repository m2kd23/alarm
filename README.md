# Alarm

내부망 PC에서 업무 중 발견한 일정이나 텍스트를 빠르게 **업무 알림(Reminder)**으로 등록하고 관리하기 위한 Windows용 경량 알림 프로그램입니다.

인터넷 연결이나 외부 클라우드 서비스를 사용하지 않고 **사용자 PC에서 독립적으로 실행**하는 것을 기본 방향으로 합니다.

## 주요 기능

- 문서·그룹웨어·웹페이지 등에서 텍스트 선택 후 지정 단축키로 알림 등록
- 선택한 텍스트에서 날짜와 시간 자동 인식
- 날짜 또는 시간이 없는 경우 직접 입력
- 정시, 5분 전, 10분 전, 30분 전, 1시간 전, 1일 전 등 사전 알림 설정
- 업무 설명 및 관련 파일·폴더 경로 등록
- 알림 조회·수정·삭제·완료 처리
- 설정된 시간에 Windows 알림 표시

## 기본 사용 흐름

```text
업무 중 텍스트 선택
        ↓
지정 단축키 두 번 입력
        ↓
선택 텍스트 자동 가져오기
        ↓
날짜·시간 자동 분석
        ↓
알림 등록창 표시
        ↓
설명 / 사전알림 / 파일경로 입력
        ↓
저장
        ↓
설정 시간에 Windows 알림 표시
```

## 입력 예시

```text
8월 21일 오후 3시 AI 교육계획 보고
```

자동 인식 예시:

```text
날짜 : 2026-08-21
시간 : 15:00
내용 : AI 교육계획 보고
```

## 알림 등록 항목

| 항목 | 설명 |
|---|---|
| 제목 | 선택한 텍스트 또는 업무 제목 |
| 날짜 | 업무 예정일 |
| 시간 | 업무 예정시간 |
| 사전 알림 | 5분 전, 10분 전, 1시간 전 등 |
| 설명 | 업무 관련 추가 메모 |
| 파일/폴더 | 관련 업무자료 경로 |

## 시스템 구성

별도의 웹서버, Python 서버, 데이터베이스 서버 없이 사용자 PC에서 독립적으로 실행하는 **Standalone 방식**을 기본으로 합니다.

```text
사용자 PC
│
├─ Alarm.exe
├─ 설정파일
└─ 로컬 데이터
   └─ 알림 일정
```

## 데이터 저장

알림 정보는 사용자 PC 내부에 저장하는 것을 원칙으로 합니다.

주요 저장 항목:

- 제목
- 일정 날짜
- 일정 시간
- 알림 시간
- 업무 설명
- 파일 경로
- 완료 여부
- 생성 일시

외부 서버로 업무정보를 전송하지 않는 구조를 기본으로 합니다.

## 보안 원칙

공공기관 내부망 사용을 고려하여 다음 원칙을 적용합니다.

- 외부 인터넷 및 외부 API 호출 최소화
- 업무정보 로컬 저장
- 그룹웨어 ID/PW 등 인증정보 미수집
- 불필요한 개인정보 미수집
- 관리자 권한 없이 실행 가능하도록 구성
- 로그에 비밀번호·개인정보 등 민감정보 기록 금지
- 외부 라이브러리 및 오픈소스 라이선스 사전 확인

## 설치 및 실행

배포 파일을 원하는 위치에 복사합니다.

```text
C:\KOMIR\Alarm\
```

프로그램을 실행합니다.

```text
Alarm.exe
```

필요한 경우 Windows 시작프로그램에 등록하여 PC 로그인 시 자동 실행하도록 설정할 수 있습니다.

## 개발 환경

구현 방식에 따라 변경될 수 있으나 다음 구성을 권장합니다.

## 개발 목표

> **업무를 하다가 발견한 일정을 가장 빠르게 알림으로 등록한다.**

기존 업무환경을 변경하지 않고 사용자가 현재 보고 있는 문서나 시스템에서 필요한 내용을 선택하여 즉시 업무 알림으로 전환할 수 있는 경량 업무지원 도구를 지향합니다.
