# 설치 안내

## 권장 설치

1. 배포받은 `InternalAlarmApp_v1.0.zip`의 압축을 사용자 쓰기 가능한 폴더에 풉니다.
2. `InternalAlarmApp.exe`를 실행합니다.
3. Windows가 파일 출처 경고를 표시하면 기관의 소프트웨어 반입·검증 절차에 따라 해시와 배포자를 확인합니다.

관리자 권한과 별도 .NET Runtime 설치는 필요하지 않습니다. 프로그램 폴더를 네트워크 드라이브에서 직접 실행하지 말고 로컬 디스크에 복사해 사용하십시오.

## 업데이트

트레이 메뉴에서 프로그램을 종료한 뒤 기존 실행 파일과 문서를 새 버전으로 교체합니다. 일정 DB는 `%LOCALAPPDATA%\InternalAlarmApp\data\alarm.db`에 있으므로 프로그램 폴더를 교체해도 유지됩니다. 기관 정책에 따라 업데이트 전에 해당 데이터 폴더를 백업하십시오.

## 제거

1. 트레이 메뉴에서 종료합니다.
2. 프로그램 폴더를 삭제합니다.
3. 일정 데이터도 지우려면 `%LOCALAPPDATA%\InternalAlarmApp`을 삭제합니다.
4. 자동 실행을 사용했다면 제거 전에 설정에서 해제합니다.
